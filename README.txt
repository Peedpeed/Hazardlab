Earth Hazard Lab - installable app (PWA)
1. Upload ALL files in this folder to the same place on an https host (e.g. GitHub Pages: new repo > upload files > Settings > Pages > deploy from main branch).
2. Open the https link on your phone.
   Android Chrome: menu > Install app / Add to Home screen.
   iPhone Safari: Share > Add to Home Screen (needed for notifications).
3. In the app: Settings > Alerts on this device > turn on Notifications / Vibrate.
Keep index.html named exactly index.html. To update later, upload the new index.html over the old one.
